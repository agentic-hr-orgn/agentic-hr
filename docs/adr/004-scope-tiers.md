# ADR 004: Scope Tiers
Tier 1 Must Ship: Auth, approvals, audit, connectors, employees, payroll - product does not exist without these
Tier 2 Should Ship: Job Poster, Code Tester, Helpdesk, Training - cut one at a time if behind
Tier 3 Stretch: Voice interviews, LinkedIn auto post, ask-your-data - only after Stage 13
Cut Ladder: Drop Tier 3 first -> Performance -> Training -> Helpdesk -> Code Tester -> monthly report. Never cut approvals, audit, tenant isolation, payroll tests
